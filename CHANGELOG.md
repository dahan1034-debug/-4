# Changelog

## 0.4.0 — Multi-weapon combat, radar scope, and upgrade economy
- Added weapon mode cycling with missile, cannon, and rocket behavior.
- Added synthesized audio cues for launch and impact events.
- Improved HUD readability with weapon state and battlefield context.
- Connected upgrade-panel events and persisted upgrade data in localStorage.
- Extended the mission loop with credits and weapon selection depth.

## 0.3.0 — Tactical overlays and persistent upgrades
- Added radar scope overlay and persistent upgrades panel.
- Added mission credits and saved upgrade values.

## 0.2.0 — Tactical awareness and countermeasures
- Added RWR, flares, and updated missile tracking / AI behavior.

## 0.1.0 — Initial prototype
- Added the first playable browser-based flight combat prototype.
